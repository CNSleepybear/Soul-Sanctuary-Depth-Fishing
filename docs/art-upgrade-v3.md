## 本轮变化

### 地形与水面

京都、中国、赛博、英国、法国和德国的地标构建器未调用 `createIsland()`，造成地标悬空。`BaseLocation` 现在补齐共享地形，工厂方法具有幂等性。每个场景都有命名地形根节点，回归检查用垂直射线确认渔夫脚下存在地面。

水面使用水平面片替代透明立方体。瓦片共用相同高度与精确边界，避免侧壁与交叠造成网格。完整覆盖岛下水域，五档透明度从 0.96 衰减至 0.12；泡沫变细，倒影改为短横向色块。这里是有意采用的平面几何例外，角色、建筑和植物继续使用方块。

瀑布从整圈三层水幕收束为三处窄跌水，起点接近岛面，落点接近水面。岩壁成为可读的主体，水流为其补充动态。

### 岸景与动态

新增 `ShoreLife`：四组成簇花园、低灌木、岩石与植被；冬季覆雪、沙地色与城市设备按地点区分。木栈钓位与现有渔夫脚底对齐，带支柱、木箱、布、水桶和小岸灯，保留抛竿线路。

芦苇轻摆，五组蝴蝶或夜间光点漂移，六条小鱼沿外侧水域游动。静物按实例批次提交，动态矩阵复用，更新循环不新建向量或颜色。资源由地点统一销毁。

### 界面

`LocationIllustration` 为 12 个地点绘制独立 SVG 旅行插画，用于营地目的地卡和选址网格。锁定状态降低饱和度与透明度，解锁和选中状态沿用原逻辑。

铭牌加入地点编号压印；工具按钮合成统一底座；镜头控件采用黄铜色并支持键盘。钓线安全色由荧光绿改为浅鼠尾草绿。面板使用深绿墨色、暖金边与纸色文字。400×300 下主按钮移到左下，避免与工具栏重叠。

移除 `#app::before` 的窗口级灰色径向蒙层，让空白桌面保持透明。场景自身保留轻雾和灯火。

附带修复首次工具栏点击被阻止冒泡、导致音频未解锁的问题：首次手势监听改为捕获阶段，不改变已保存的音乐偏好。

```powershell
npm run typecheck
npm run lint
npm test
npm run build:vite
npm run test:smoke
$env:ART_OUTPUT='screenshots/art-v3'
node scripts/art-review.cjs
```

- 77 项单元/集成检查通过，包括 12 场景地形支撑、氛围更新和资源清理。
- 2 项 Electron 冒烟检查通过：三首音乐播放、循环与偏好保存；营地 → 护符 → 鱼饵 → 出发 → 抛竿，以及图鉴和灵魂面板。
- 400×300、560×420、640×480 实机截图；检查小窗主按钮与工具栏无重叠、营地与出发按钮不越界。
- 12 地点全部低于 140 draw calls / 150,000 三角形预算。统计是软件 GPU 环境的提交量检查，不代表实测 60 FPS。
- 四角 alpha 均为 0。截图使用独立临时用户目录，避免写入玩家存档。
- lint 无错误；有 3 条原有 warning（主进程 console 与单元测试未使用变量）。
