# 第四轮美术升级：微缩旅行纪念品

日期：2026-10-24。保留透明桌面、正交体素、离线程序化生成、现有玩法和存档。

## 参考方法

沿用 [Cast n Chill](https://store.steampowered.com/app/3483740/Cast_n_Chill/) 的水面与前景层次、[Tiny Glade](https://store.steampowered.com/app/2198150/Tiny_Glade/) 的手作微缩细节、[WEBFISHING](https://lamedeveloper.itch.io/webfishing) 的清晰剪影和 [Chillquarium](https://store.steampowered.com/app/2276930/Chillquarium/) 的收藏陈列。只借鉴构图、光色与节奏，没有下载、复制或打包参考游戏素材。

## 本轮变化

### 地形、水面与光色

- 浮岛轮廓增加地方化低频起伏，岩层采用更整体的色块变化；渔夫脚下及交互通道排除地表突起。
- 水面降低灰白浅水感，改成深浅分层、断续岸线泡沫、非均匀高光和聚集在地标下方的破碎倒影。
- 远景继续用悬浮小岛与云，不使用灰色全屏雾。泛光只增加已有像素的 alpha；工具栏改为内阴影，透明桌面四角保持全透明。

### 十二个地点

- 京都：鸟居柱脚、描金牌匾、上翘顶梁、连续拱桥和分层樱花枝冠。
- 中国：竹亭台基、托木、格栅、月洞与石桥，竹叶更疏朗。
- 美国：楼层线脚、窗框、消防平台、招牌灯箱和断续湿地霓虹；移除满地网格。
- 英国：错缝砖墙、石材隅石、红色电话亭、铁艺栏杆与暖光街灯。
- 法国：四腿收分铁塔、开放桁架、咖啡座、餐具和旧书摊。
- 德国：木屋榫架、阳台、雪枕、冰凌、柴堆与劈柴工具。
- 意大利：彩色立面、拱窗、阳台、水痕、拱桥与带船夫长桨的贡多拉。
- 丹麦：不同层数与屋顶节奏的联排屋、帆船索具、卷帆、桶箍和港灯。
- 冰岛：黑教堂木构与白窗棂、苔原、地热台地、三层极光和分层蒸汽。
- 泰国：叠层佛塔、翘角、长尾船、叶筏河灯与纸罩天灯。
- 埃及：砂岩节理、积沙、方尖碑、柱鼓、棕榈和热霾。
- 希腊：蓝顶肋线、镂空钟楼、三角梅、连续石阶、白帆与露台茶具。

### 角色、鱼类与反馈

渔夫放大到更易读的比例，补充腰包、衣扣和草帽细节；两只猫同步提高小窗辨识度。普通鱼增加背部与腹部的阶梯色块。浮标涟漪改为断续波纹，雨雪、萤火与花瓣使用各自可读的形状。

### 界面

统一深绿纸墨、暖金和地点强调色，重做铭牌、按钮、工具栏、卡片和选中态。小窗关键文字提升到 9–12px，常规交互目标至少 24×24 CSS px，焦点轮廓更清晰。持续/强调动效在 `prefers-reduced-motion` 下逐项停用，提示保持静态可见。
