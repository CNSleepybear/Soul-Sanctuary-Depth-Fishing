# 美术升级方向 v2 — 微光圣地 / Luminous Sanctuaries

> 本文件是 2026-10 第二轮美术升级的唯一美术标准（Single Source of Art Truth）。
> 所有场景、UI、角色与特效改动都必须先满足这里的硬性规范，再做风格发挥。
> 上一轮成果见 [`art-upgrade-2026-10.md`](./art-upgrade-2026-10.md)。

---

## 0. 一句话方向

**把「方块浮岛」升级为「会呼吸的发光微缩圣所」：更少的颜色、更准的光、更深的景、更多的细节，以及一套像纸与墨一样安静的 UI。**

保留的艺术基因（不可破坏）：

- 透明桌面悬浮窗，周围必须是透明像素；
- `OrthographicCamera` 正交微缩视角；
- 纯 `BoxGeometry` 体素语言，无外部纹理/模型；
- 冷启动无需联网，全部程序化生成；
- 一次 Render Run 的 GPU 开销仍然按"桌面小挂件"预算（60fps @ 400×300 内部缓冲）。

允许新增的（本轮引入）：

- 屏幕空间后处理（调色 / 泛光 / 暗角 / 抖动），但必须保留 alpha；
- 更细的体素网格（0.25 单位）与更多实例化装饰；
- 半透明的体积光、光斑、远景剪影层（仍用 Box/Plane + 纯色材质）。

## 2. 五条视觉支柱

### 2.1 构图：每一帧都是一只雪花球

每个场景必须能读出三个景深层：

1. **前景框（Foreground frame）**：画面左下或右下 1–2 组低矮道具（岩石、芦苇、栏杆、倒木、船头），用来制造"窥视"感与尺度参照。高度不超过岛屿高度的 35%，不得遮挡渔夫与浮标。
2. **主体景（Focal diorama）**：浮岛与地标建筑，占画面高度 45–70%，是唯一的高对比区域。
3. **远景层（Background depth）**：透明桌面窗口不能画地平线——任何世界固定的背景板都会在半圈环绕中跑到岛前面，并且给桌面蒙上一层灰。因此远景改用两种「悬浮物」：岛后上方 8–14 单位处的 2–3 块微型浮岛 + 2 团半透明云（颜色 = `veil` 提亮），以及岛底周围的一层薄雾。它们随镜头自然环绕，只做深度参照，不抢主体。

硬性约束（钓鱼交互点固定，不得让场景压住）：

- 渔夫站位：`(-2.8, 1.5, 3.9)`；
- 浮标待机/落点：`(1.8, -1.91, 7.0)` 附近 2 单位半径必须可读；
- 岛面高度：`y = 1.5`；水面：`y ≈ -1.93`；
- 地标不得占据画面中心 1/3 的正中，优先放在 2/3 分割线上（参考 Dorfromantik）。

### 2.2 色彩：每个地点一套 6 色脚本

每个场景必须在 `location-data.ts` 的 theme 中体现（或场景内本地常量）：

| 角色 | 用途 | 规则 |
|------|------|------|
| `key` 主光色 | 太阳/月亮/主要方向光 | 饱和低、明度高；暖色场景 30–40° 色相 |
| `shadow` 阴影色 | 环境光、雾、暗部 | **永远不是纯黑**，用主光的补色压暗 |
| `base` 岛体色 | 石/土/草 | 中低饱和，明度差 ≥ 18% 形成层次 |
| `accent` 地标色 | 建筑/地标主色 | 唯一允许中高饱和的颜色，占画面 < 12% |
| `glow` 光源色 | 灯笼/窗/霓虹/极光 | 只出现在小面积高亮处，交给泛光 |
| `veil` 氛围色 | 远景、雾、光尘 | 与 `shadow` 同族，明度略高 |

规则：

- 单帧颜色数（不含 UI）控制在 **10–14 个色相族**；同族只做明度变化。
- 暖/冷必须成对出现：暖主光 + 冷阴影，或冷主光 + 暖局部灯。
- 地标高饱和色面积 < 12%，避免"整岛一个色"。
- 草地/雪地/沙地必须有 3 档明度变化 + 少量暖色/花色点缀。

### 2.3 光照：低环境光 + 清晰主光 + 局部暖光

- 环境光（AmbientLight）强度 **0.35–0.6**，颜色取 `shadow`；不允许再出现"整岛灰白"。
- 半球光（HemisphereLight）强度 **0.45–0.7**，天空色 = `veil`，地面反射色 = `base` 的暖色偏移。
- 主方向光强度 **1.6–2.4**，色温明确（黄昏 2600–3200K 视觉暖橙 / 月夜 7000–9000K 冷蓝 / 正午中性）。
- 轮廓光（rim，第二方向光）强度 **0.35–0.8**，从主光反方向打，用于把地标从远景色里"抠"出来。
- 局部点光每个场景 **2–4 个**：灯笼、窗、火堆、霓虹、水灯。必须带轻微呼吸/闪烁（0.08–0.2 Hz）。
- 阴影：主光开阴影，mapSize ≥ 1024，阴影范围收紧到岛体（±11），`normalBias ≈ 0.04`；禁止大面积死黑。
- 每个场景至少 1 处「体积光」或「光尘」：用 2–4 片半透明发光 Plane/Box（additive、opacity 0.04–0.12）制造光柱。

### 2.4 体素：0.25 网格、块面化剪影、两层明暗

- 所有新增几何按 **0.25 单位**对齐（`VOXEL = 0.25`）；主体道具尺寸必须是 0.25 的整数倍。只有花/草/鱼鳍等"毛发级"细节允许 0.0625–0.125，且必须 ≥ 2 像素。
- 禁止在内部渲染分辨率下不可见的尺寸（< 0.06 单位 = < 1px）。
- 每个物体最多用 **3 档明度**（受光面 / 侧面 / 暗面）表达体块，不靠复杂几何。
- 剪影优先：树、屋顶、船、地标必须在纯黑剪影下仍可辨认。
- 细节密度：岛面 60% 有内容，但中心与渔夫通道保持空；装饰按"簇"分布，不做均匀撒点。

### 2.5 动态：一切都在呼吸，但不要抢戏

- 镜头：自动绕行 0.02–0.04 rad/s，垂直浮动 ±0.10–0.14，周期 6–8s。
- 水面：2 层波纹（慢 0.4Hz / 快 1.1Hz）、岸边泡沫呼吸、偶尔的闪光。
- 植被：树冠整体 ±1–2° 摆动，粒子/花瓣下落周期错开。
- UI：120–240ms `cubic-bezier(0.22, 0.61, 0.36, 1)`，不要在每帧里读写布局。
- 禁止"每帧随机"的抖动；所有随机使用 seeded PRNG 或固定 phase。

## 3. 技术规范

### 3.1 渲染与后处理

- 内部渲染尺寸 = 窗口尺寸（现状），正交相机 `viewSize` 收紧到 **8.2–8.6**，目标点上移到 `(0, 1.6, 0)`，让岛体占满画面 70%。
- 新增 `PostFX` 单 pass 管线（`RenderTarget` → 全屏四边形）：
  - **调色**：lift/gamma/gain + 饱和 + 轻微 split-tone（暖高光/冷阴影）；
  - **泛光**：亮度阈值提取 + 1/4 降采样两级模糊，只叠加到亮部（灯笼、霓虹、极光、水面高光）；
  - **暗角**：只作用于 alpha > 0 的像素，绝不能给桌面加灰；
  - **抖动**：4×4 Bayer dither，消除大面积渐变 banding。
- alpha 必须正确保留；`omitBackground` 截图仍是透明底。
- 后处理参数按地点 theme 覆盖（`art.grade`）。
- 保留 `antialias: false` 与 `image-rendering: pixelated`。
- **Shader 政策**：物体级禁止自定义 `ShaderMaterial`（保持体素材质语言）；只允许渲染管线级的全屏后处理 shader（`PostFX.ts`），且必须可关闭/降级。

### 3.2 性能预算（400×300 内部缓冲，桌面挂件）

| 项目 | 上限 |
|------|------|
| draw calls / 帧 | ≤ 140（当前基线约 60–90） |
| 三角形 / 帧 | ≤ 150k |
| 后处理 | ≤ 8 次 draw，RT ≤ 400×300 |
| 每帧 GC | 0 次新分配（update 里禁止 new Vector3/Color） |
| 场景切换 | < 120ms，无残留灯光/材质 |

### 3.3 工程约束

- TypeScript strict，`npm run typecheck` / `npm run lint` 必须通过；
- 新增文件需带文件头注释；
- 不改公共 API 的现有含义（`BaseLocation` 的 abstract 方法与生命周期保持）；
- 不修改存档格式；
- 所有字符串走 i18n（新增 UI 文案必须中英双语）；
- 材质优先走 `MaterialCache`，几何在 `destroy()` 中释放。

## 4. 分层规范

### 4.1 浮岛（所有地点共享）

新 `FloatingIsland` 负责：

- 7 层台地：草面（y = 1.5）、土坡、3 层岩层与水下岛尖，边缘做阶梯状悬崖；
- 岛缘轮廓：低频噪声 + 每地点 1 个"特征缺口"（瀑布口/码头/沙滩），不再是无意义的锯齿；
- 岩层带 2–3 条地层色带 + 少量苔藓垂挂；
- 草面 3 档明度 + 花朵/草簇/小石/踏脚石路径；
- 岛底悬空碎岩 3–5 块（小体素），增强"浮岛"叙事；
- 实例化渲染，保持 ≤ 6 个 InstancedMesh。

### 4.2 水面（所有地点共享）

新 `SanctuaryWater` 负责：

- 水面从岛缘（r ≈ 4.9）延伸到 r ≈ 7.9，但外缘必须**渐隐**（用顶点色 alpha 或更密集的分段透明材质），不再出现"咖啡滤纸"；
- 近岸：浅水色（`waterColor` 提亮 35%）+ 连续闭合的阶梯泡沫环带（呼吸缩放，不用重叠透明块拼圈）；
- 深水：深色 + 横向波纹条（2 层，方向相反）；
- 倒影：地标颜色的竖向拉长色块，随波纹摇晃（additive，opacity 0.15–0.3）；
- 闪烁：小而扁的高光 Box（30–40 个，实例化）；
- 外缘与桌面交界处不能有硬边灰边。

### 4.3 悬浮远景

- 每个地点由 BaseLocation 自动生成 3 块微型浮岛（半径 10.5–13.5）+ 2 团半透明云，颜色 = `veil` 提亮，不接收光照（`MeshBasicMaterial`）；
- 岛底薄雾 4 片、opacity ≤ 0.09，随呼吸缓慢漂移；
- 场景可以在此基础上追加自己的悬浮物（热气球、纸灯、飞鸟），但不得使用世界固定的地平线剪影板。

### 4.4 场景地标

每个地点必须有且只有一个"视觉锚点"（主地标），满足：

- 高度 ≥ 岛面以上 2.5 单位；
- 轮廓在 1 秒内可辨认；
- 最多 3 种主色；
- 带一处暖光/冷光焦点；
- 相机自动绕行时，从 4 个方向看都不会穿帮。

## 6. UI 视觉规范 v2

### 6.1 色板

| Token | 值 | 用途 |
|-------|-----|------|
| `ink` | `#16191a` | 面板基底 |
| `inkSoft` | `rgba(22,25,26,0.94)` | 半透明面板 |
| `paper` | `#efe7d6` | 主文字 |
| `paperDim` | `#b9b4a6` | 次要文字 |
| `gold` | `#e0b978` | 高亮/货币/选中 |
| `sage` | `#a9c3a0` | 正向/成功 |
| `coral` | `#dd8a7a` | 危险/张力 |
| `sky` | `#9db6cf` | 稀有/信息 |
| `line` | `rgba(239,231,214,0.14)` | 分隔线 |

规则：面板用深墨色 + 1px 纸色描边（透明度 12–18%）；选中态用金色描边 + 轻微外发光；不出现纯白纯黑。

### 6.2 字体与字号

- 数字/英文标签：`VT323`（已有），用于货币、编号、HUD 数值；
- 中文正文：`'Microsoft YaHei', 'PingFang SC', sans-serif`；
- 字号阶：7 / 8 / 9 / 11 / 13 / 16 / 20px（窗口小，不再多）；
- 字重只用 400 / 600；标题可加 0.5px 字距。

### 6.3 组件规则

- 圆角：小 3px、中 6px、大 10px；
- 按钮高度 ≥ 22px，点击区域 ≥ 28px；
- 卡片：深底 + 顶部 1px 高光 + 底部 1px 暗边；
- 图标：统一 16×16 线性 SVG，1.25px 描边，`currentColor`；
- 面板打开/关闭：150–220ms 淡入 + 4px 上移；
- 滚动条：4px、金色 25%；
- 所有面板必须适配 400×300 / 560×420 / 640×480。

### 6.4 布局

- 主界面：左上地点铭牌（半透明、不压岛）、底部中央主按钮、右下工具组；
- HUD：顶部张力条与线耐久，底部抛竿次数/金币；
- 营地/图鉴/护符/鱼饵：内容区滚动，底部固定主操作；
- 图鉴预览统一使用正交相机 + 透明背景 + 像素化放大。
