# 体素圣地美术升级

保留透明桌面窗口、正交相机和 BoxGeometry 体素语言，以暖米色、鼠尾草绿、低饱和石材与局部灯火统一画面。

参考：[WEBFISHING](https://lamedeveloper.itch.io/webfishing) 的轻松钓鱼氛围、[Tiny Glade](https://store.steampowered.com/app/2198150/Tiny_Glade/) 的微缩景观层次。所有几何和界面均为项目原创实现，未引入参考游戏素材。

## 已实现

- 所有 12 个地点共用连续轮廓、分层断崖与局部苔藓的浮岛。岛体和外侧水面采用 InstancedMesh，地形四层分别一次提交，替代原本每块单独提交的方式。
- 每个地点独立的水色、动态水光及岸边细节：樱花、芦苇、香草花丛、积雪石块、沙地植物、城市设备。
- 调整环境补光、主光和阴影范围，保持下半部可读，保留地点的局部色光。
- 京都重新分组鸟居、石灯与桥梁，重做阶梯式拱桥，调整樱花树冠和前后景，修复锦鲤被地面遮挡的问题。
- 中国场景缩小高塔、整理竹林层次；赛博场景改为开放式阶梯楼群，保留霓虹和全景可见的前景。
- 渔夫增加草帽饰带、围巾、背包、面部和靴子；鱼增加鳃线与鳞片细节；浮标采用暖红与奶油白并缩短旗杆。
- 修复所有地点缺失的氛围更新调用、额外灯光切场景后残留、传说鱼呼吸动画破坏体素比例，以及鱼自身动画覆盖世界坐标的问题。
- 营地、图鉴、护符、鱼饵与钓鱼 HUD 统一色板和字体；修复未插值的主题样式值。营地拥有独立滚动内容和固定出发底栏。
- 图鉴增加默认已发现鱼预览、空状态、清晰的选中状态和键盘操作；主界面添加地点铭牌与原创线条图标。
- 适配 400×300、560×420、640×480；降低自动环绕速度，保留透明窗口。

## 检查与复现

```powershell
npm run typecheck
npm run lint
npm run test
npm run build:vite
npm run test:smoke
node scripts/art-review.cjs
```

单元检查覆盖传说鱼比例、12 地点氛围回调与切换后的场景清理。Electron 冒烟检查使用独立用户目录，覆盖营地 → 护符 → 鱼饵 → 出发 → 抛竿。

截图脚本在 `screenshots/art-review/` 输出各地点、营地、图鉴及总览。透明原图之外，`japan-preview.png` 和 `contact-sheet.png` 使用浅色底方便审阅。截图来自实际 Electron 渲染。
