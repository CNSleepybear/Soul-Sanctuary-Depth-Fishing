# 🎣 Fishing Game Market Research & Competitive Analysis

> **Project**: Soul Sanctuary: Depth Fishing (灵魂避难所 · 深渊垂钓)
> **Date**: 2026-06-02
> **Art Style**: Retro Low-Poly 3D + Pixel Rendering (400×300 upscale)

---

## 1. Executive Summary

The fishing game genre spans casual mobile hits to hardcore simulators. The sweet spot for our target — a **browser-based, low-poly 3D fishing experience with meditative/soulful atmosphere** — lies at the intersection of:

- **Casual/Relaxation** (Animal Crossing fishing, Stardew Valley fishing)
- **Collection/Progression** (Pokémon Snap-like compendium, rare hunting)
- **Atmospheric Immersion** (Dredge-like tone without horror, Firewatch-like presence)
- **Web Accessibility** (instant play, no download, shareable)

### Key Market Gap

There is **no major browser-based 3D fishing game** that combines:
1. Distinctive low-poly art aesthetic
2. Global cultural fishing locations
3. Collectible spirit fish compendium
4. Deep progression without predatory monetization
5. Meditative ASMR-like atmosphere

## 2. Competitive Landscape

### 2.1 Tier 1: Major Commercial Titles

| Game | Platform | Strengths | Weaknesses | What We Learn |
|------|----------|-----------|------------|---------------|
| **Stardew Valley** | PC/Console/Mobile | Perfect fishing minigame integration; progression through skill levels, bait, tackle; seasonal/weather variety | Fishing is side content, not the core loop | Mini-game tug-of-war mechanic is proven addictive; skill tree + gear progression |
| **Dredge** | PC/Console | Lovecraftian fishing; day/night cycle; boat upgrades; inventory tetris; hand-drawn style | Horror tone limits audience; premium purchase | Inventory management = strategic depth; day/night dramatically changes risk/reward |
| **Animal Crossing: NH** | Switch | Seasonal fish; museum collection; social sharing; relaxing tone | No skill-based depth; time-gated | Collection compendium is powerful motivator; seasonal FOMO drives retention |
| **Fishing Planet** | PC/Console/ Mobile | Hyper-realistic simulation; 20+ locations; tournament PvP | Steep learning curve; heavy monetization | Location variety = content breadth; competitive leaderboards add infinite replayability |
| **Ridiculous Fishing** | Mobile | Addictive core loop (cast→dodge→collect); progression treadmill; charming art | Single-axis gameplay; short session length | Simple core loop ≠ shallow; upgrade path is the main progression driver |
| **Cat Goes Fishing** | PC | Open-world fishing; charming pixel art; sandbox feel | Limited content depth | Exploration rewards; "what will I catch next?" drive |

### 2.2 Tier 2: Browser/Web-based Fishing Games

| Game | Strengths | Weaknesses |
|------|-----------|------------|
| **Fisherman's Life** (WebGL) | Accessible; simple mechanics | Shallow content; no meta-progression |
| **Various itch.io fishing games** | Creative; experimental | Usually one-off experiences; no retention |
| **Webfishing** (Steam) | Social multi-player fishing; avatar customization; retro aesthetic | Requires download; limited locations |

### 2.3 Key Insight: The Browser Gap

There is a **clear market gap** for a polished, retention-focused browser fishing game with:
- ✅ Real 3D graphics (WebGL/Three.js)
- ✅ Deep progression system (weeks of content)
- ✅ Distinctive art style (not generic)
- ✅ Multiple locations with unique biomes
- ✅ Collection compendium
- ✅ No download required

## 3. Player Psychology & Retention Mechanics

### 3.1 Core Motivations (Self-Determination Theory)

| Need | How Fishing Games Satisfy It |
|------|------------------------------|
| **Autonomy** | Choose where to fish, what bait, what rod; free exploration |
| **Competence** | Skill-based mini-game mastery; gear optimization; knowledge of fish patterns |
| **Relatedness** | Share rare catches; compare collections; community discovery |

### 3.2 Retention Loops (Why Players Keep Coming Back)

```
┌─────────────────────────────────────────────┐
│              CORE RETENTION LOOP             │
│                                              │
│   CAST ──▶ WAIT ──▶ BITE ──▶ MINI-GAME      │
│     ▲                          │             │
│     │                          ▼             │
│     │                    CATCH / LOSE        │
│     │                          │             │
│     │                          ▼             │
│     │               COLLECT / SELL           │
│     │                    │                   │
│     │                    ▼                   │
│     └──── UPGRADE ◀── EARN CURRENCY         │
└─────────────────────────────────────────────┘
```

### 3.3 Engagement Drivers (Ranked by Impact)

1. **Collection Compulsion** (85% impact): Filling the fishpedia drives session length. "Just one more cast to find the rare one."
2. **Progression Treadmill** (78%): Unlocking new rods, baits, and locations provides clear goal structure.
3. **Variety & Surprise** (72%): Random rare spawns, weather-dependent fish, time-of-day exclusives.
4. **Skill Mastery** (65%): Getting better at the mini-game; feeling of "I earned this catch."
5. **Atmosphere & Escapism** (60%): The low-poly sanctuary aesthetic itself is the reward.

### 3.4 Anti-Churn Strategies

| Strategy | Implementation |
|----------|---------------|
| **Daily Bounty** | "Catch 3 fish in Kyoto today" — rewards premium currency |
| **Weather Windows** | Rain spawns rare Electric Eel in Thailand; fog spawns Ghost Koi in UK |
| **Time-Gated Rare Fish** | Midnight-only spawns; dawn/dusk exclusive species |
| **Weekly Tournament** | Biggest fish caught this week in each location (leaderboard) |
| **Seasonal Events** | Cherry blossom season = special Sakura Koi in Japan |
| **Streak Bonuses** | Consecutive days played = multiplier on sell price |

## 4. Target Audience Personas

### Persona A: "Chill Seeker" (40% of audience)
- **Age**: 22-35
- **Motivation**: Relaxation, stress relief, atmosphere
- **Plays**: 15-30 min sessions, 3-5x/week
- **Values**: Visual beauty, music, no pressure
- **Monetization**: Cosmetic only; resists pay-to-win

### Persona B: "Completionist Collector" (35% of audience)
- **Age**: 18-30
- **Motivation**: 100% fishpedia, all achievements
- **Plays**: 1-2 hour sessions, daily
- **Values**: Clear goals, rarity hunting, progress tracking
- **Monetization**: Willing to pay for storage expansion, special bait

### Persona C: "Competitive Angler" (25% of audience)
- **Age**: 16-28
- **Motivation**: Leaderboard ranking, biggest fish
- **Plays**: Short burst sessions, but frequent
- **Values**: Skill expression, optimization, bragging rights
- **Monetization**: Will pay for slight advantages (better rod durability etc.)

## 5. Monetization Model (Ethical F2P)

### 5.1 Recommended: "Cosmetic + Convenience" (No P2W)

| Category | Free | Premium |
|----------|------|---------|
| **Rods** | 12 base rods (1 per location) | Cosmetic rod skins (visual only) |
| **Bait** | Standard bait (infinite) | Special bait (higher rare%, buy with in-game gold OR premium) |
| **Storage** | 50 fish inventory | Expand to 200 (one-time purchase) |
| **Locations** | All 12 unlocked | Early access to new locations (2-week head start) |
| **Cosmetics** | Default bobber | Themed bobbers, rod trails, catch effects |
| **Energy** | 20 casts per session (recharges 1/5min) | Energy potion (30 extra casts) |
| **Fishpedia** | Full compendium | Golden fishpedia skin |

### 5.2 What We AVOID
- ❌ Loot boxes / gacha for fish
- ❌ Pay-to-win rods (premium = sidegrade, not upgrade)
- ❌ Energy that forces payment (20 free casts = ~15 min play)
- ❌ Ads between every cast

### 5.3 Revenue Projection (Conservative)
- Conversion rate: 3-5% (industry standard for casual web games)
- ARPPU: $5-15/month
- Target: Sustainable solo/duo dev operation

## 6. Platform & Technical Feasibility

### 6.1 Why Browser (WebGL/Three.js)

| Advantage | Detail |
|-----------|--------|
| **Zero friction** | No app store approval, no download, share a link |
| **Cross-platform** | Works on desktop Chrome/Edge/Firefox/Safari + mobile browsers |
| **Easy updates** | Deploy to CDN, instant for all players |
| **Viral potential** | Shareable links; embeddable on social platforms |
| **Existing codebase** | Soul Sanctuary already uses Three.js r128 |

### 6.2 Technical Constraints

| Constraint | Mitigation |
|------------|------------|
| **Mobile performance** | 400×300 render buffer already very light; LOD for fish models |
| **Save data** | localStorage for offline; optional cloud save via simple API |
| **Asset size** | Procedural low-poly meshes (no texture files); minimal download |
| **Audio** | Web Audio API for generative ambient + SFX |

> **"A meditative low-poly fishing journey across 12 soul sanctuaries around the world. Cast your line into pixelated waters, collect spirit fish, and find your sanctuary."**

1. **🎨 Distinctive Art Style**: Retro low-poly 3D with flat shading + pixel render — instantly recognizable, not another generic "fishing sim"

## 9. Risk Analysis

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| Content drought (players exhaust fish) | Medium | High | 100+ fish at launch; seasonal additions |
| Browser performance on mobile | Medium | Medium | 400×300 buffer already optimized; test early |
| Player retention drop after week 1 | Medium | High | Daily system, rare spawn rotation, community events |
| Scope creep | High | High | MVP defined clearly; phase 2/3 roadmap |
| Competition from Steam fishing games | Low | Low | Browser = different market; zero-friction access |

## 10. Conclusion & Recommendation

**Build it.** The market gap is real. The existing Soul Sanctuary codebase provides ~30% of the needed tech (rendering, scene management, particle systems, 12 locations). The low-poly style differentiates strongly. Browser accessibility removes all friction.

**Recommended scope for MVP:**
- 3 fishing locations (Japan, Iceland, Thailand)
- 15 fish species (5 per location)
- Core cast→bite→reel mini-game
- Basic collection fishpedia
- 3 rod upgrades
- localStorage save

**Phase 2:** All 12 locations, 60+ fish, daily challenges, leaderboard
**Phase 3:** Multiplayer fishing holes, seasonal events, mobile optimization
